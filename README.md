# Cave Crawlers — Proximity Voice

Proximity voice chat for **Cave Crawlers**. You hear your friends in 3D, from where they are standing:
- voices get quieter with distance, and walls muffle them;
- reverb and echo match the size of the cave;
- a shout carries further than normal talk, and a whisper only reaches people next to you;
- dead players can only talk to each other, and whisper to the player they are watching.

Unofficial fan mod. Not affiliated with Heroic Pyxel. It doesn't touch the game's files, saves, store or gameplay:
it only adds the BepInEx loader and this mod. Players without the mod are not affected at all.

## Install
1. Download **`ProximityVoice-Setup.exe`** from the [latest release](../../releases/latest).
2. Run it and press **Install**.
3. Press **▶ Play**.

To update, open the setup and press **Play**. It downloads the new version on its own before starting the game.
Everyone in the lobby needs the same version. The game will tell you if someone's version is different.

## Settings
In the game: **Settings → Audio**, at the bottom: voice chat mode (push to talk / always on / voice activation),
push-to-talk key, microphone, mic volume, voice volume, a "hear yourself" mic test, and a volume slider for each
player in your room.
